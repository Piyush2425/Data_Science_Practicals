# Data Science Lab Repository

This repository contains a series of Data Science laboratory assignments and exercises, complete with Jupyter notebooks, datasets, and documentation.

## 📋 Contents

### Jupyter Notebooks
- **DS_Lab_1.ipynb** through **DS_Lab_10.ipynb** - 10 comprehensive data science labs covering various topics and techniques

### Datasets
- **Iris.csv** - The classic Iris dataset containing measurements of iris flowers
- **Social_Network_Ads.csv** - Social network advertising dataset for classification tasks

### Output Formats
- **html/** - HTML versions of all labs for web viewing
- **pdf/** - PDF versions of labs for printing and offline access

### Environment
- **DS/** - Python virtual environment with all required dependencies

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook or JupyterLab

### Setup

1. Activate the virtual environment:
   ```bash
   # On Windows
   DS\Scripts\Activate.ps1
   
   # On macOS/Linux
   source DS/bin/activate
   ```

2. Launch Jupyter:
   ```bash
   jupyter notebook
   ```

3. Open any lab notebook (e.g., `DS_Lab_1.ipynb`) to get started
